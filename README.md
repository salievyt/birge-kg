# BIRGE

Платформа ОшТУ для проектов, идей, клубов, мероприятий, поиска команды и модерации активности.

Продакшен-домены: фронтенд `https://birge.deo-core.codes`, API `https://birge.backend.deo-core.codes`.

## Структура

- `frontend` — Next.js интерфейс платформы (чистая архитектура).
- `backend` — Django + Django REST Framework API (чистая архитектура).

Слои (и справка, и фасад):

Джанго:
- `core` — домен (модели).
- `api.infrastructure.repositories` — доступ к данным.
- `api.application.services` — use cases (авторизация, дашборд, модерация).
- `api.presentation` — веб-адаптеры (views, serializers, urls).

Frontend:
- `lib/domain` — сущности и доменные константы.
- `lib/infrastructure` — API-клиент и репозитории данных.
- `lib/application` — use cases (хук-контроллер приложения).
- `components` — презентационные компоненты.

## Запуск

```bash
npm run install:all
python3 backend/manage.py migrate
python3 backend/manage.py seed
npm run backend
npm run dev
```

Фронтенд откроется на `http://localhost:3000`, API — на `http://127.0.0.1:8000/api/`.

### Проксирование API и админки

Next.js перенаправляет на бэкенд (`https://birge.backend.deo-core.codes` по умолчанию):
`/api/*` → API, `/admin/*` → Django admin, `/static/*` и `/media/*` → статика/файлы.
Цель переопределяется переменной окружения `BACKEND_ORIGIN` (например,
`BACKEND_ORIGIN=http://127.0.0.1:8000` для работы фронта с локальным бэкендом).

## Деплой бэкенда на Vercel

Бэкенд подготовлен к нулевой настройке (Vercel определяет Django по `manage.py`):

- Vercel-проект: **Root Directory = `backend`**, всё из `backend/pyproject.toml`
  (`[tool.vercel] entrypoint = "birge.wsgi:application"`, Python 3.12 через `.python-version`).
- **Автомиграция**: каждый деплой выполняет `python manage.py migrate --noinput`
  по Build Command `[tool.vercel.scripts] build` (после установки зависимостей, до деплоя).
  `collectstatic` Vercel запускает сам (статику раздаёт CDN).
- Переменные окружения для продакшена:
  - `DATABASE_URL` — обязателен, **Postgres** (Neon/Supabase/база Vercel). Без него миграции
    применяются к эфемерному SQLite, и данные не сохраняются (runtime — read-only FS).
  - `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=0`
  - `DJANGO_ALLOWED_HOSTS=<имя>.vercel.app,...` (домены `birge.*` уже разрешены)
  - `DJANGO_TRUSTED_ORIGINS`, `DJANGO_CORS_ORIGINS` — доп. origin'ы при необходимости
  - `DJANGO_COOKIE_DOMAIN=.deo-core.codes` — чтобы session/csrf-cookie доходили до
    браузера через прокси фронта (`birge.deo-core.codes/admin`, `.../api/...`).
- Админка на **Jazzmin** (только светлая тема, тёмная отключена): без переключателя тем,
  без дата-атрибута `data-bs-theme="dark"` и без bootswatch-тёмных стилей. Тема задаётся
  в `JAZZMIN_SETTINGS` (`"theme": "default"`, `"show_theme_chooser": False`).
- Админка доступна на `https://birge.deo-core.codes/admin/` — фронт перенаправляет
  (308) на `https://birge.backend.deo-core.codes/admin/`, чтобы session/CSRF-cookies
  ставились на домен бэкенда. Логин: суперпользователь, созданный в БД
  (`python3 backend/manage.py createsuperuser`).
- Ограничение: `backend/media/` (загрузка изображений) на Vercel не сохраняется —
  для постоянного хранения подключите `django-storages` (S3/R2).

## Реализовано

### Общие
- Тёмная тема (переключатель, учёт `prefers-color-scheme`), анимированный прелоадер, скелетоны загрузки, toast-уведомления, восстановление раздела по `#hash`.
- A11y: управление фокусом при смене экрана, `aria-live`/`aria-label`, `prefers-reduced-motion`.
- Защита: `#hash`-роутинг без SSR, CSRF через same-site cookie, права «чтение всем, запись модераторам».

### Каталог и главная
- Главная: слоган, статистика сообщества, график активности, топ факультетов (кликабельны → факультет), направления, стена достижений, хаб разделов.
- Каталоги проектов, идей, клубов, мероприятий и людей; детальные страницы с комментариями, участниками, join/leave и голосованием за идею.

### Новые страницы (вторая волна)
- **Мой кабинет** — свои проекты/идеи/клубы/события, избранное, счётчики и непрочитанные уведомления.
- **Публичный профиль** человека (проекты, клубы, события, навыки).
- **Уведомления** — фильтр по типам, отметка прочитанными (по одному и все).
- **Страница события** — регистрация/отмена, напоминание, организатор, список участников, лимит мест.
- **Календарь** — помесячная сетка событий, переход между месяцами.
- **Факультеты** — статистика и вкладки студентов/проектов/клубов/событий.
- **Избранное** — закладки на проекты/идеи/клубы/события.
- **Подбор команды** — проекты с открытыми ролями и люди в поиске команды + заявка на роль.
- **Лента новостей** — объявления, ближайшие события, новые проекты, идеи недели.
- **Стена достижений** — присвоение достижений модераторами, иконки.
- **Голосование за идеи** — голос/отзыв голоса, рейтинг.
- **Онбординг / заявка на вступление** — форма для неавторизованных + модерация заявок.
- **Модерация** — детальный просмотр идей и заявок с одобрением/отклонением, создание проектов/клубов с загрузкой логотипа (`POST /api/upload/`).
- **Помощь и правила** — правила, FAQ, путеводитель по разделам.
- **Настройки/экспорт** — выгрузка своих данных в JSON.

### API
- Django-модели и REST API: профили, проекты, идеи, клубы, мероприятия, объявления, комментарии, голоса, избранное, уведомления, достижения, заявки, напоминания о событиях, календарь, лента, подбор команды, экспорт.
- Тесты: `python3 backend/manage.py test api` (14).
